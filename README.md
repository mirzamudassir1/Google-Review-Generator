# Google Review Generator

A simple web-based tool that generates natural-sounding Google review suggestions based on the positive feedback selected by the customer.

The goal is to make it easier for customers to turn their genuine experience into a well-written review without having to write everything from scratch.

## Features

* Generate reviews based on selected positive feedback
* Randomized review generation for variety
* Simple and user-friendly interface
* Fast and lightweight
* Copy generated reviews with a single click
* Responsive design for desktop and mobile
* No account or login required

## How It Works

1. The customer selects the aspects they liked about the business.
2. The application processes the selected feedback.
3. A review is generated using different combinations of the selected points.
4. The customer can review, edit, and copy the generated text.
5. The customer can then use it as a starting point for their Google review.

## Example

**Selected feedback:**

* Friendly Staff
* Good Service
* Clean Environment
* Quick Delivery

**Generated review:**

> Had a great experience! The staff were friendly and the service was quick and efficient. The place was clean and everything was handled smoothly. Would definitely recommend this business.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Google-Review-Generator.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd Google-Review-Generator
```

### 3. Run the application

Since this is a frontend project, you can simply open `index.html` in your browser.

For development, you can also use **VS Code Live Server**.

## Purpose

Writing a review can sometimes be difficult even when a customer has had a great experience. This project provides a quick way to convert selected positive feedback into a natural review draft.

**The generated review should reflect the customer's actual experience and can be edited before posting.**
